# Demo trip pictures

The sixteen photographs in this folder are the pictures of the local-mode fixture trips (`DemoTripPictures`,
`FakeData`). They are shown only by a local container and the browser tests; production never serves them.

**Origin.** Every picture here was taken by, and belongs to, the project's owner, who confirmed on 2026-11-16 that
they hold the rights to all of them and consent to their publication in this repository, including the pictures
in which people can be recognized (`soccer-match.jpg`, `soccer-warmup.jpg`).

Each file is a source already cut to 3:2 with its metadata removed. To add one, add the file and its row in
`DemoTripPictures`; `DemoTripPicturesTest` prints the width, height and placeholder the row must carry.
